Probeaufgabe Angular

Diese Anwendung setzt die Anforderungen der Aufgabe sowie die genannten Erweiterungen und optionalen Techniken um. Als Datenquelle dient die Star Wars API.

Anforderungen

  • check_circle Alle Personen aus dem People-Endpoint werden mit Namen in einer Liste angezeigt.
  • check_circle Ein Klick auf eine Person öffnet die Detailansicht mit Name, Größe, Gewicht, Geburtsjahr und Geschlecht.
  • check_circle Neue Personen lassen sich lokal hinzufügen; dafür wird die API nicht verwendet.

Erweiterungen

  • check_circle Einträge können aus der Liste gelöscht werden.
  • check_circle Die Liste kann nach Namen gefiltert werden.

Optionale Techniken

  • check_circle Neue Einträge werden in einem Dialog erfasst.
  • check_circle Namensliste und Detailansicht erscheinen nebeneinander; die Auswahl wird per Routing gesteuert.
  • check_circle Die Oberfläche verwendet Angular Material.
